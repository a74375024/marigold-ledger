# M3: Live Events (and the rest of M2)

Install over the previous build as in `docs/m0-test.md`.

## Live Events

| Area | How to check | Pass |
|---|---|---|
| Open | Yellow key, or OK on the Live Events tab | The board: hero with the focused game, rows of tiles |
| First open | Wait a few seconds the first time | "Loading this week's games…", then rows fill in; later opens are instant |
| Rows | Up/Down | Your teams, Live now, then one row per sport; group labels Live / Final / Starting Soon / Later Today / days |
| Tiles | Left/Right | Status pill and clock, both teams with scores while live, the channel it's on, "+ N backup feeds" |
| Sports column | Left from a row's first tile | Sports with live counts; Up/Down scrolls the board, OK jumps |
| Watch | OK on a live game | Plays the best channel; the others are automatic backups |
| Event guide | Left while watching a game | That sport's games; OK switches, Right lists other ways to watch, Left the sports column |
| Flip | Up/Down while watching a game | The sport's live games, with "2 / 5 · Team A at Team B" |
| Where to Watch | Red key on a tile | Every channel and feed for the game; picking one starts there |
| Upcoming | OK on a later game | Detail card with Remind Me; at start time a card appears in the corner (OK watches) |
| Same source | Watch a game, switch away, come back within 6 hours | Starts on the feed you were on |
| My Sports | Settings › Live Events › My leagues, My teams | Pick leagues, favourite teams, reminders; the board follows |
| Settings | Settings › Live Events: Game schedule, Games not on my channels, Show scores | The board follows at once |

Requests: the week's schedule only for the leagues you follow (about once a
day), and scores once a minute per league with a game on, only while the
board or the event guide is open.

## Playback (M2)

| Area | How to check | Pass |
|---|---|---|
| Freeze | A feed that freezes mid-show | "Buffering…", then "Reconnecting…" after about 10 s, then the next feed |
| Sources | Red key › Always start with | The pinned feed plays first next time |
| HLS channels | A channel that stayed silent in Legacy's direct mode | Plays through the built-in TS proxy |
